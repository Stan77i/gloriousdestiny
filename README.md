# Glorious Destiny

Site officiel (puis PWA) de Glorious Destiny : vitrine, catalogue, commandes WhatsApp, rendez-vous, stock, livraisons, tableau de bord.

- Architecture : [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
- Stack : React, TypeScript, Vite, Tailwind CSS, Supabase (PostgreSQL)

## Démarrer

```bash
npm install
npm run dev
```

Statut : Phase 2 (fondations techniques) en cours, après audit de l'architecture.
