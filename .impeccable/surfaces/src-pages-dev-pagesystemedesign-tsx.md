# Surface brief — Système de design Glorious Destiny (Phase 3)

Scope: design system complet (jetons, typographie, composants, graphiques, états) + page vitrine vivante `/systeme-design` (développement) et `/admin/systeme-design` (personnel). Modes : Operate pour l'administration, Persuade pour le site public ; le système sert les deux.

Audience : clientes sur mobile (Douala, Yaoundé, Garoua, Abidjan), professionnelles, diaspora ; équipe interne pour l'admin.
Contraintes : couleurs imposées noir profond / doré / ivoire ; référence d'interface donnée par le client (Caelo : noir chaud, doré miel, géométrique, pilules) ; pas de clichés de salon ; aucune donnée inventée (exemples marqués « Exemple »).
Direction : épinglée par le brief client (pas de tirage) ; voir contrat.

## Direction contract

THESIS: L'interface est l'étiquette. Le noir profond et le filet d'or des emballages Glorious Destiny (marbre noir veiné d'or) deviennent le langage de l'écran. Refuse le salon rose pailleté et le tableau de bord SaaS sombre à néon.

OWN-WORLD: Fond noir chaud #0d0b09, surfaces étagées brun-noir, filets 1px. L'or (#d6a756) s'emploie comme une dorure à chaud : rare, fin, pour l'action principale, l'état actif, le focus. Texte ivoire. Bodoni Moda (didone de magazine de mode) pour l'affichage public ; Urbanist pour l'interface, les chiffres, l'admin. Coins 12px sur les panneaux, pilules sur les contrôles. Signature : la veine d'or, un filet organique tracé en SVG qui sépare et souligne.

STORY: Le visiteur comprend une marque de beauté premium sérieuse ; l'équipe trouve chaque chiffre et chaque action sans chercher.

FIRST VIEWPORT: Page vitrine : grand titre Bodoni « Système de design » à gauche, photo d'usage réelle du produit (Lace Melting Spray, fournie par le client) à droite, hauteur de l'écran sur grand écran, veine d'or qui se trace sous le titre ; index des sections en pilules sous le titre.

FORM: Étiquette de luxe en marbre noir et dorure (1re de 7 candidates : étiquette, flacon, coffret, magazine de mode, vitrine de parfumerie, carnet de rendez-vous, ticket de caisse). seed: none (unavailable) — direction épinglée par le client, qui a imposé « noir profond ; doré ; ivoire en couleur secondaire », « premium, moderne, éditoriale, minimaliste, élégante », et donné le tableau de bord Caelo comme référence d'interface ; aucun tirage n'a été fait. Interaction signature : la veine d'or se dessine (stroke) à l'apparition ; reflet doré sur l'action principale au survol.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
